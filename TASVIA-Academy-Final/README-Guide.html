Everything runs on free plans: Firebase (Spark), GitHub Pages and your existing GoDaddy domain.

1Install this final version

  1. Firebase → Firestore Database → Rules → select all, delete, paste 2-firebase-rules.txt → Publish.
  2. GitHub → tasvia → Add file → Upload files → drag all 10 files from the 1-upload-to-github folder → Commit changes.
  3. Delete the old folders on GitHub: tasvia-phone, tasvia-upload-files 2, tasvia-parent-update (open each → ⋯ → Delete directory → Commit). Keep CNAME.
  4. Wait 2 minutes, open https://app.tasviaacademy.com and reload (⌘ + Shift + R).
  5. On phones: remove the old home-screen icon, then add it again (Safari → Share → Add to Home Screen; Chrome → ⋮ → Add to Home screen).

Never delete CNAME or firebase-config.js on GitHub – the app needs both.

2Add a teacher

  1. Firebase → Authentication → Users → Add user → their email + a starting password.
  2. Firebase → Firestore → Data → Staff → Add document → Document ID = their email in small letters → field name = their name → Save.
  3. Send them app.tasviaacademy.com, their email and password. They can change it with Forgot password?
  4. In the app: More → Staff & salaries → Add teacher (for attendance and salary).

To remove a teacher: delete their document in Staff and their user in Authentication. They lose access immediately.

4Parents

  • Each child has a private parent page: homework, attendance, marks, fees, notices, photo – in English, తెలుగు or हिन्दी.
  • Send it once: Students → child → Parent page → Send link on WhatsApp, or More → Parent page links for everyone.
  • Parents with two children see both names at the top of the page and can switch.
  • Link shared with the wrong person? Tap New link – the old one stops working.
  • Everything else still reaches parents on WhatsApp: absence alerts, homework, receipts, fee reminders, progress reports, report card image.

5Every month

  • Fees → Fee reminders for pending fees
  • More → Staff & salaries → pay salaries → send slips
  • More → Expenses & profit → add rent, electricity etc. and check profit
  • More → Backup spreadsheets → download all 5 and keep them in Google Drive
  • Term end: More → Report cards & ID cards → download → Print / Save PDF

6Android APK (for teachers' phones)

  1. Go to pwabuilder.com → type https://app.tasviaacademy.com → Start.
  2. Package for stores → Android → Generate package. Package ID com.tasviaacademy.app, App name TASVIA Academy.
  3. Download → unzip → send the .apk on WhatsApp (phones ask to allow “Install unknown apps”).
  4. Email the signing key file and its password text to tasviaacademy@gmail.com. Without them you can never update the APK.
  5. Optional: upload the .aab to Google Play (one-time $25 developer account). Use app-store-icon-1024.png as the store icon.

iPhones: Safari → app.tasviaacademy.com → Share → Add to Home Screen. (An App Store app needs a $99/year Apple developer account.)

7If something goes wrong

ProblemFix
“Not on staff list”Add their email (small letters) in Firestore → Staff.
Forgot passwordSign-in screen → type email → Forgot password? → check Gmail (and Spam).
Old version showingReload with ⌘ + Shift + R (Mac) or close and reopen the app on the phone.
Parent link says “Setting up…”Open that child in the staff app once – the page publishes in seconds.
Parent link says “not valid”Link was replaced or the child was removed – send a fresh link.
Nothing loads for everyoneFirebase free daily limit reached (very unlikely) – it resets next day. Check Firebase → Usage.
app.tasviaacademy.com stops openingGoDaddy → DNS: the app CNAME must point to tasviaacademy-alt.github.io. GitHub → Settings → Pages: domain saved, HTTPS ticked.

8Keep safe

  • Passwords for Gmail, Firebase, GitHub and GoDaddy – only the owner should have them.
  • Turn on 2-step verification on tasviaacademy@gmail.com and GitHub.
  • Optional extra safety: Google Cloud → APIs & Services → Credentials → Browser key → Websites: app.tasviaacademy.com/* and tasvia-academy.firebaseapp.com/*.
